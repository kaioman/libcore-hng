# utils モジュール一覧と責務

## 1. 概要

`src/libcore_hng/utils/` 配下のモジュールは、アプリケーション全体で共通して利用する補助機能を提供する責務を持ちます。  
本ディレクトリは、ビジネスロジックそのものではなく、設定初期化、ログ、暗号化、ファイル操作、文字列処理、システム補助などの横断的な処理を集約します。

- コア責務は `src/libcore_hng/core/` を参照してください
- 追加で利用する共通処理は `src/libcore_hng/utils/` に寄せてください
- 1 モジュール 1 責務を基本とし、責務が重複しないようにしてください

## 2. モジュール一覧

| モジュール | 主な責務 | 補足 |
| --- | --- | --- |
| `app_core.py` | アプリ初期化、設定ロード、グローバル設定管理 | `init_app()` と `get_config()` の入口です |
| `app_logger.py` | ログ設定の統一 | アプリ起動時のロガー構成です |
| `app_logger_mixin.py` | ロガー利用時の補助機能 | 既存ロガーの利用補助です |
| `crypto.py` | 暗号化・復号化処理 | 設定ファイルの暗号化支援です |
| `enums.py` | 列挙型定義 | 共有定数や識別子の定義です |
| `file_renamer.py` | ファイル名変更支援 | 連番や命名規則に基づくリネームです |
| `helpers.py` | 汎用補助関数 | 共通処理の小部品群です |
| `imageops.py` | 画像処理補助 | 画像変換や操作支援です |
| `io_manager.py` | 入出力処理支援 | ファイル読み書きの抽象化です |
| `mathops.py` | 数値計算補助 | 計算ユーティリティです |
| `secret_manager.py` | シークレット取得 | GCP Secret Manager 連携です |
| `system.py` | システム情報・環境補助 | OS や実行環境の確認です |
| `textops.py` | 文字列処理補助 | テキスト整形や変換です |
| `thread_local_helpers.py` | スレッドローカル補助 | スレッドごとの状態保持支援です |

## 3. 追記ルール

新しいモジュールを追加した場合は、以下のルールに従って更新してください。

1. モジュールの責務を 1 文で整理してください
2. `utils/` 配下の一覧表に 1 行追加してください
3. 実装コードの詳細は別途追記せず、責務の要約を維持してください
4. 既存モジュールの責務が重複する場合は、機能分離を優先してください

## 4. 保守方針

- この文書は「実装詳細の説明書」ではなく、「機能の責務一覧」として運用してください
- 具体的な内部実装は対象モジュールのコードを参照してください
- 追加機能が出た場合でも、表への行追加だけで追記コストを抑えられます
